## Privacy contract
Raw text, image OCR, sensitive-text suggestions and private two-key checks use ONLY_ON_DEVICE with no cloud fallback. Check and download Nano explicitly. Emulator Nano is unavailable; status exceptions mean UNKNOWN/unavailable, never supported. Missing Nano does not trigger cloud or template answers.

The independent hybrid request uses PREFER_ON_DEVICE and may fall back only after manual redaction, explicit synthetic confirmation, preview and exact payload approval. Nothing auto-sends. Source, spans and confirmation edits invalidate approval and accepted answers; dispatch consumes approval once before suspension. Only the approved redacted request string is handed to Firebase. A ledger records the exact UTF-8 application text supplied to the SDK, bytes/hash/time and SDK inference source. It does NOT claim to capture serialized HTTP or TLS bytes. Attempt records are not successful cloud proof.

The canonical shared/nano/contract.json is packaged unchanged as an Android asset; detection/verifier use its quote-only schemas and prompts. Native structured output REQUIRES @Generable/@Serializable types and Firebase KSP-generated MlKit companions; manual JsonSchema helper objects compile but fail at runtime on-device. QuoteTypes.kt mirrors quote-only wire fields and list bounds with @Guide, and generateObject uses the generated firebaseAISchema. Shared prompts are loaded from the packaged canonical asset; strict parsers validate fields, kind/status domains, bounds and exact quotes. Types use String kind/status (strict parser enforces canonical enums), so no claim of schema enum constraints on-device. No schema success is claimed before physical runtime testing. Suggestions require manual selection, not automatic spans. Two-key checks cover every explanation, draft, deadline, action and amount claim with strict exact original evidence, current revision, accepted response identity and a fresh opaque response receipt. A conservative Android guard currently supports only entire verbatim claims identical to a complete source line and exact evidence; paraphrases remain UNKNOWN even if correct. All model mismatch/unsupported verdicts become UNKNOWN, never fake deterministic contradiction or proven absence. Empty/missing/invented evidence fails. Model-generated wording is not a truth guarantee. Writer/addressee and other unique role placeholders are restored locally only after the private check passes. Avoid redacting deadline/amount facts that the response must quote: if exact source evidence is not preserved the check fails closed.

Originals, responses, approvals and ledger are process-memory only, no SavedState, databases, analytics or content logging; backup disabled. Photo Picker opens input and decodes to memory without persistent permission. Camera requires Android's external camera contract and a narrowly scoped private FileProvider cache file: this is the unavoidable temporary camera handoff, deleted after callback and on startup. It is not a persistent original store. Process death clears text/bitmap session. No raw data is sent for crash/debug logging.
